# 01-PRODUCTION: 実際のサイト（本番機能）

## 1. 責務概要
ユーザーが実際に原稿を執筆・推敲・管理するための本番サイトの全機能を統括する領域です。

## 2. 含まれる機能一覧
- **原稿編集 & グリッド表示**:
  - `contenteditable` エディタ（`#e`）
  - 原稿用紙グリッド描画（CSS `linear-gradient` & `--cs` 変数）
  - 行番号表示、字数・行数カウント、文字種検出（全角スペース、半角カナ、禁則文字、非表示文字等）
- **文字数設定（横の文字数・縦の文字数）**:
  - 全体デフォルト文字数設定（`getGlobalCols()` / `saveGlobalCols()`）
  - 原稿ごとの個別文字数設定（`customCols`）
  - 18〜40文字（最大100文字）までの自由な動的変更
- **データ保存・復元**:
  - `localStorage` によるリアルタイム自動保存（`n_d`, `n_w`, `n_c` 等）
  - ZIPアーカイブ一括エクスポート / インポート機能
  - ゴミ箱、復元機能、章・フォルダ階層管理
- **ユーザー認証 & クラウド同期（Supabase）**:
  - Supabase Auth によるユーザーログイン / サインアップ UI
  - 原稿データおよび設定のクラウドへの非同期自動同期（`user_stories` / `user_settings`）
  - オフライン時のローカルフォールバック保護

## 3. 境界の保証
- **Preview への非依存**: Production コード内に Preview 専用のテストフックや iframe ハードコードは含まれません。
- **動的文字数の維持**: 30文字は初期状態の「デフォルト値（初期選択肢）」としてのみ定義されており、ユーザーが20字や28字等に変更した設定を上書き・固定化するような特殊処理はありません。
